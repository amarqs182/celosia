# Shadow of the Colossus (Celosia) — R36S & Handheld Linux Port Guide

This document details the architecture, optimizations, controls, and setup for running **Celosia** (the native C++ static recompilation port of *Shadow of the Colossus*, PS2) on the **R36S** and other handhelds based on the Rockchip RK3326 SoC running **ArkOS** (or compatible distributions such as AmberELEC / UnofficialOS).

---

| Component | Specification |

## 2. Architecture & Optimizations

### 2.1 Native D1 Decompilation (2,912 Hot Functions — 98.4% CPU Cycles)
Rather than executing guest MIPS code through an interpreter or dynamic recompiler loop on the Cortex-A35, the game's execution profile was analyzed under real gameplay conditions (`r36s_prof129.log`).
- **Hot Functions Lifted**: The top 2,912 most cycle-intensive functions (accounting for **98.4% of total execution time**) were converted ahead-of-time into optimized native C++ code across 20 modular compilation units (`decomp_liftd1_00.cpp` through `decomp_liftd1_19.cpp`).
- **NEON Vectorization**: Hot matrix-vector transforms, skinning calculations, and coordinate projections use `sse2neon` and native ARMv8 SIMD instructions.
- **Black Screen Prevention**: Secondary cold functions (specifically `initlayout_0x1360508` and dynamic relocators which rely on instruction self-inspection `READ32(pc)`) are kept inside the stable recompiler runtime. This prevents memory pointer corruption during the logo-to-title screen transition (frame 230), ensuring 100% boot stability.

### 2.2 Modern Single-Pass Tonemapping & Elimination of 12 Heavy PS2 Multipass Passes
The original PlayStation 2 version achieved its ethereal aesthetic by drawing multiple full-screen passes (feedback blur, bloom dilation, luminance thresholding, stencil darkeners). On the tile-based Mali-G31 GPU, these multi-pass readbacks and frame-buffer feedback blits saturated tile memory bandwidth and drove frame times over 84 ms.

#### Disabling Legacy Multipass Passes:
1. **Bloom / Glare (`SOTC_BLOOM_SCALE=0`, `SOTC_GLOW=0`, `SOTC_NATIVE_NOGLOW=1`)**: Eliminates downsampled Gaussian blur passes and full-screen additive passes.
2. **Feedback & Screen Blur (`SOTC_NATIVE_NOFEEDBACK=1`, `SOTC_NATIVE_NOSBLUR=1`)**: Disables the recursive motion blur buffer copy.
3. **Depth of Field (`SOTC_NATIVE_NODOF=1`)**: Eliminates depth downsampling and chromatic circle-of-confusion blits.
4. **Heat Haze & Distortion (`SOTC_NATIVE_NOHAZE=1`, `SOTC_NATIVE_NOREFRACT=1`)**: Disables displacement map passes.
5. **Stencil Volume Shadows (`SOTC_NATIVE_NOSHADOWS=1`, `SOTC_BODY_SHADOWS=0`)**: Eliminates extruding shadow volume geometry passes.
6. **Secondary Particle Swarms (`SOTC_NATIVE_NOPTCL=1`, `SOTC_SAC_PARTICLES=1`)**: Thins ambient atmospheric dust emitters.
7. **Vertical / Volumetric Fog (`SOTC_NATIVE_NOVFOG=1`, `SOTC_NATIVE_ZFOG=0`)**: Replaces multipass slice fog with vertex-based distance falloff.
8. **Additive Blend Passes (`SOTC_NATIVE_NOADDITIVE=1`)**: Merges transparency passes.

#### Single-Pass Modern S-Curve Tonemapper (`SOTC_TONEMAP=1`):
To prevent the game from looking washed out or overly bright due to double-gamma application (`pow(x, 1/2.2)` applied on an already sRGB framebuffer), a zero-cost single-pass shader applies:
- An **S-Curve contrast shoulder** that preserves high-dynamic range highlights on the sky and character clothing without clipping to harsh white.
- A **re-anchored black point** ensuring deep, rich shadows and eliminating lifted milky-grey levels.
- Direct output into the 640×480 framebuffer in a single rasterization pass, dropping GPU render time from 84 ms to **2.0 – 4.5 ms**.

### 2.3 Quad-Core Multithreaded Offload Architecture
The Rockchip RK3326 contains 4 physical Cortex-A35 cores. Work is isolated and pinned across all cores:

```
┌────────────────────────────────────────────────────────┐
│               RK3326 (4x Cortex-A35)                   │
├──────────────┬──────────────┬──────────────┬───────────┤
│    Core 0    │    Core 1    │    Core 2    │  Core 3   │
├──────────────┼──────────────┼──────────────┼───────────┤
│  GameThread  │  IK Workers  │ Audio (SPU2) │  Render   │
│  Sequencer   │   char104    │  DMA Stream  │  Thread   │
│  Scheduler   │ Software VU1 │ Terrain BSP  │ Mali-G31  │
│  Input Poll  │ Bone Anime   │  Collision   │ (GLES3.2) │
└──────────────┴──────────────┴──────────────┴───────────┘
```

- **Core 0 (`SOTC_AFF_GAME=0`)**: Game loop sequencing, entity lifecycle, and player input.
- **Core 1 (`SOTC_AFF_VU1=1`, `SOTC_CHAR104=1`)**: Inverse Kinematics (Wander, Agro, Colossi limb placement), skeletal bone interpolation, and VU1 microprogram simulation.
- **Core 2 (`SOTC_AFF_AUDIO=2`, `SOTC_AFF_DMA=2`)**: SPU2 audio voice synthesis, ADSR envelopes, BGM streaming, and octree terrain collision queries.
- **Core 3 (`SOTC_AFF_RENDER=3`, `SOTC_RENDER_THREAD=1`)**: Dedicated OpenGL ES 3.2 RenderThread submitting batches directly to the Mali-G31 MP2 driver.

### 2.4 EE Cycle Pacing & Lag Compensation
- `PS2X_HOST_CLOCK_MAX_LAG=2`: Binds the maximum accumulated EE cycle deficit to 2 VBlanks. On occasional heavy scene transitions, the physics engine will not compound extra catch-up ticks in a loop ("death spiral"), ensuring immediate recovery to 60 FPS.

## 3. Gamepad & START Button Integration

### 3.1 The START Button Crash Fix
Under ArkOS and PortMaster, generic SDL2 controller configurations without an exact GUID match can interpret gamepad events as keyboard hotkeys or unmapped signals. When the user pressed `START`, SDL forwarded an unhandled exit event or triggered an EmulationStation hotkey quit.

### 3.2 Solution
1. Place PortMaster's canonical `gamecontrollerdb.txt` directly into `/roms/ports/SotC_Celosia/gamecontrollerdb.txt`.
2. SDL2 automatically matches the R36S internal gamepad device (e.g. `OpenSimHardware OSH PB Controller` or `GO-Advance Gamepad`) and assigns the `START` button to `SDL_CONTROLLER_BUTTON_START`.
3. Pushing `START` now pauses the game and displays the native in-game pause menu without exiting to EmulationStation.

## 4. Directory Structure on R36S

The port files reside on the SD card (`TF2` / `/roms/ports/`):

```
/roms/ports/
├── Shadow of the Colossus.sh           <-- Launcher displayed in EmulationStation Ports
└── SotC_Celosia/
    ├── SotC.sh                         <-- Master launch script (frequencies, affinities, flags)
    ├── ps2sotc_aarch64_pie_sdl         <-- Native compiled aarch64 binary (stripped)
    ├── SCUS_974.72                     <-- Extracted USA game ELF
    ├── gamecontrollerdb.txt            <-- PortMaster gamepad mappings
    ├── disc/                           <-- Extracted PS2 disc files
    │   ├── DATA.CVM
    │   └── SYSTEM.CNF
    ├── memcards/                       <-- Virtual PS2 Memory Card (Mcd001.ps2)
    └── sotc.log                        <-- Runtime performance and diagnostic log
```

```sh

  LOCK_PID="$(cat "$LOCKFILE" 2>/dev/null)"
  if [ -n "$LOCK_PID" ] && kill -0 "$LOCK_PID" 2>/dev/null; then
    echo "SotC already running (PID $LOCK_PID), aborting."
    exit 0
```
